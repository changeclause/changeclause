# Reporting security vulnerabilities

Use [GitHub private vulnerability reporting](https://github.com/changeclause/changeclause/security/advisories/new) for suspected vulnerabilities. If that route is unavailable, email [dev@changeclause.com](mailto:dev@changeclause.com).

Include the affected version or commit, a minimal sanitized reproduction, the expected security boundary, and the observed impact. Do not include live credentials, customer data, or private repository contents. Avoid publishing exploit details in a public issue before maintainers can review the report.

Ordinary bugs, documentation errors, and feature requests belong in [Issues](https://github.com/changeclause/changeclause/issues). Consult the documented [evidence and trust limits](docs/architecture/evidence-and-trust.md) when reporting a result that appears to overstate what was verified.
